# sidh-mod

A Claude Code mod that adds a band above the prompt: **rAIdar**, a daily AI-news radar, on the left, and an animated dev team reacting to the job you hand Claude on the right.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install sidh-mod --marketplace mrds91/sidh-mod
```

Answer `y` to add the marketplace, then pick a scope.

From a shell:

```
claude plugin install sidh-mod --marketplace mrds91/sidh-mod
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `mrds91/sidh-mod`, then Add plugin.
